# 布局与个人任务记录管理迭代

日期：2026-10-29。对应本轮提供的模板列表和账户设置参考图，以及桌面布局、小屏操作、语义标签和键盘焦点要求。

## 1. 页面与管理方案

| 区域 | 本轮行为 |
|---|---|
| 模板列表 | 收起大幅宣传区，突出分类与封面网格；卡片直接标明所需图片数量和使用入口 |
| 详情/制作 | 桌面左侧模板缩略图、要求和上传/提交，右侧当前模板的个人任务；小屏改为单列 |
| 账户弹窗 | 显示 Java 返回的演示身份及 ID，提供个人记录入口、身份切换与退出；不展示虚构邮箱/密码或账单功能 |
| 个人历史 | 全部、进行中、已完成、失败与模板组合筛选，使用 Java 查询整个历史，分页保留条件 |
| 任务详情 | 只读弹窗展示完整结果、输入素材、任务编号、时间、阶段状态和失败原因 |

沿用 Java 会话和数据库归属检查。切换/退出立即卸载旧身份的输入、图片、任务调度器和在途请求；重新进入同一身份后，从 Java 恢复记录。前端没有把用户 ID 当作授权参数，其他身份直接读取素材/任务/结果仍由后端返回 404。

历史显示“当前已加载条数”，不伪造总数。选择筛选条件会重建查询作用域，取消旧请求并重置游标；状态与模板传给现有 Java API。ACTIVE 仍按页发现当前模板范围内的未完成任务，终态后停查；“已完成”筛选也能在任务完成后接收结果。进行中已扫描完整 ACTIVE 列表后不重复展示分页按钮。

同一次页面可见性恢复中，账户和任务区共享一个身份核验 Promise，避免两次核验互相使对方过期，导致任务区停留在暂停状态。旧身份的迟到响应仍按序号/epoch 丢弃。

## 2. 可操作性

- 账户、详情均使用原生 dialog，关联标题/描述并声明模态语义；背景不可交互，锁定背景滚动。
- Tab / Shift+Tab 在弹窗控件中循环；Escape 或有名称的关闭按钮关闭；返回触发按钮，触发记录已不在页面时返回主要内容。
- 身份切换使用 aria-disabled 和操作防重入，保持被选择按钮的焦点；再次选择当前身份不会重新登录。
- 上传输入有“选择图片 N”稳定标签及状态说明；移除后焦点返回相应文件输入，提交反馈获得焦点。
- 状态有文字和图形反馈，查询错误独立于业务失败；刷新图标、预览和详情按钮有可理解标签。
- 所有主内容可通过跳转链接聚焦。尊重减少动画偏好，不依赖悬停才能操作。
- 320px 使用同一套单列布局，可纵向滚动完成上传、筛选和弹窗查看，不另外制作移动端产品。

## 4. 取舍与边界

继续采用两个可自由选择的演示身份，不提供真实身份保证。此次修改不扩展支付、积分、密码重置、账户注销或复杂模板后台。个人记录管理采用筛选、分页、查看和恢复查询；原任务重试、记录删除和下载仍不在实现范围。

筛选条件和上传草稿不跨刷新保存；已受理任务、阶段、素材和结果保存在原有服务端存储，页面关闭不影响执行。本轮没有修改已应用的数据库迁移。
